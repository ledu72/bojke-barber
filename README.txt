BOJKE BARBER V8 - ONLINE

V8 koristi PostgreSQL bazu preko DATABASE_URL i spreman je za Render + Supabase.

LOKALNO:
1. Instaliraj Node.js 20+
2. npm install
3. postavi DATABASE_URL
4. npm start

ONLINE:
1. Napravi Supabase projekat i uzmi Postgres connection string.
2. Na Render-u napravi Web Service iz GitHub repozitorijuma.
3. Build command: npm install
4. Start command: npm start
5. Environment variable: DATABASE_URL=<Supabase connection string>
